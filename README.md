# My通知

「忘れたくない」を、かんたんに。iPhone向けの通知・リマインダーアプリです。

ワンタイム通知、リピート通知、曜日指定通知、日付指定通知、スケジュール通知、集中タイマーの6種類から、用途に合わせて設定できます。アカウント登録は不要です。

旧アプリ名：リピート通知
