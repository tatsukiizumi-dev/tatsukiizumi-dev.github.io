# My通知

「忘れたくない」を、かんたんに。iPhone向けの通知・リマインダーアプリです。

ワンタイム通知、リピート通知、曜日指定通知、日付指定通知、スケジュール通知、集中タイマーの6種類から、用途に合わせて設定できます。アカウント登録は不要です。

旧アプリ名：リピート通知

# ねこカルテ

猫の体重・ごはん・お世話・通院を、家族で共有しながら記録するiPhone向けアプリです。

猫ごとに記録する項目を選べて、予定の通知、グラフ・カレンダー、支出の管理にも対応。家族の「おうち」に招待コードで参加すれば、同じ記録をいっしょに見て書けます。

- App Storeで見る（公開準備中）
- [サポート](https://pacific-moat-960.notion.site/2bc9bbbfb9618312b6c601ab8ed79d30)
- [プライバシーポリシー](https://pacific-moat-960.notion.site/3d89bbbfb96180d6bd7fc969dccd40fc)
